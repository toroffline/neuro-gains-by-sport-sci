# ระบบประสาทและต่อมไร้ท่อตอบสนองต่อการออกกำลังกาย

ฉบับปรับปรุงมีทั้งภาษาไทยและอังกฤษ ความยาวภาษาละ 4 นาที ภาพ 1280 × 720 พิกเซล 30 เฟรมต่อวินาที

- เปิด `site/index.html` สำหรับภาษาอังกฤษ หรือ `site/th/index.html` สำหรับภาษาไทย
- กดลิงก์ภาษาในส่วนท้ายหน้าเพื่อสลับภาษา ข้อความ ปุ่ม เสียงพากย์ และคำบรรยายเปลี่ยนตามภาษา
- วิดีโออังกฤษ: `site/Neuroendocrine_Responses.mp4`
- วิดีโอไทย: `site/th/Neuroendocrine_Responses_TH.mp4`
- MP4 มีคำบรรยายติดภาพ ส่วนหน้า WebGL เปิด–ปิดคำบรรยายได้

## เผยแพร่บน GitHub Pages

1. แตก ZIP แล้วอัปโหลดทั้งโครงการลง repository บน branch `main` รวม `.github/workflows/pages.yml` และโฟลเดอร์ `site/`
2. ไปที่ Settings → Pages แล้วเลือก GitHub Actions
3. รัน workflow ชื่อ Publish GitHub Pages หรือ push ไปยัง `main`
4. เปิด URL ที่งาน deployment แจ้งไว้

ชุดนี้เตรียมพร้อมเผยแพร่ แต่ยังไม่ได้อัปโหลดไปยังบัญชี GitHub

## การแก้ไขท่าทาง

- ตรึงความยาวแขนขา และปรับความสูงประมาณ 7–8 ส่วนศีรษะ
- ท่าวิ่งด้านข้างมีช่วงลงเท้า ถีบพื้น แกว่งขา และลอยตัว พร้อมแกว่งแขนสวนขา
- ใช้ inverse kinematics คำนวณเข่า และให้ความเร็วเท้าช่วงสัมผัสสัมพันธ์กับสายพาน
- ท่ายกดัมเบลเป็น standing dumbbell curl: เท้าอยู่นิ่ง ลำตัวตั้งตรง ต้นแขนและข้อศอกไม่แกว่งตามดัมเบล
- ช่วงงอข้อศอกในภาพประมาณ 25–125 องศา เป็นตัวอย่าง ไม่ใช่ช่วงที่ทุกคนต้องฝึกเหมือนกัน

ตรวจ 2,400 ตำแหน่งแล้วว่า ความยาวแขนขาคงที่ เท้าไม่ทะลุพื้น และท่าวิ่งไม่มีช่วงรับน้ำหนักด้วยสองเท้าพร้อมกัน ผลอยู่ใน `qa/motion-report.json`

การเคลื่อนไหวสร้างด้วยสมการ ไม่ใช่ข้อมูล motion capture หรือการวิเคราะห์เฉพาะบุคคล

## เนื้อหาและเสียง

ภาษาไทยใช้เสียงสังเคราะห์ Microsoft Niwat Neural บทพากย์ปรับถ้อยคำให้เหมาะกับเวลาและการฟัง โดยคงสาระหลักของฉบับอังกฤษ รายการอ้างอิงคงชื่อบทความภาษาอังกฤษเพื่อให้ค้นต่อได้ง่าย

ดูข้อจำกัดของหลักฐานใน `science-notes.md`: ความล้าส่วนกลางมีหลายสาเหตุ BCAA ไม่ใช่วิธีป้องกันความล้าที่พิสูจน์ชัดเจน และผลฮอร์โมนต้องแปลตามบริบทของแต่ละคน

## เสียงฉบับ neural (v3)

ใช้ Microsoft Niwat Neural แทนเสียงเดิม เพิ่มจังหวะพักระหว่างประโยค และปรับการอ่านชื่อทางสรีรวิทยา เวลาคำบรรยายสร้างใหม่จากไฟล์เสียงจริง มีไฟล์เสียง MP3 แยกให้ด้วย การสร้างเสียงซ้ำใช้ neural_th.py และ requirements-voice.txt; เว็บผู้ชมเล่นไฟล์ที่สร้างเสร็จแล้ว จึงไม่ต้องมีบัญชีหรือ API key


## โมเดลและคำอธิบายฉบับ v4

เพิ่มภาพตัดหลอดเลือด เม็ดเลือดแดงทรงเว้าสองด้าน เส้นใยกล้ามเนื้อมีลาย ไตและต่อมหมวกไต รังไข่ กระดูกภาพตัดพร้อมโครงข่ายด้านใน โครงร่างโมเลกุลกลูโคส และหลอดเก็บเลือด ป้ายหมายเลขในภาพตรงกับคำอธิบายใต้เครื่องเล่น ซึ่งเปลี่ยนตามฉากทั้งไทยและอังกฤษ อ่านทั้งหมดได้ใน OBJECT_GUIDE_TH.md รูปทรงเหล่านี้เป็นภาพสรุป ไม่ใช่ภาพสแกนหรือแบบจำลองกายวิภาครายบุคคล


## แก้การเปิดเสียง v4.1

ไฟล์ index.html ที่อยู่ชั้นนอกของ ZIP จะพาไป site/index.html อัตโนมัติ หรือเปิด START_HERE.html ได้เช่นกัน เว็บภาษาไทยอยู่ที่ site/th/index.html เก็บโฟลเดอร์ site และไฟล์เสียงไว้ด้วยกัน เมื่อเผยแพร่ GitHub Actions ให้ใช้โฟลเดอร์ site ตาม workflow ที่แนบไว้

ใช้ MP3 เป็นไฟล์เสียงหลักและ WAV เป็นตัวสำรอง หากเสียงโหลดไม่ได้ ภาพและคำบรรยายยังเล่นต่อได้ พร้อมปุ่มลองเปิดเสียงใหม่ ลิงก์ไฟล์ MP4 ใช้เล่นแยกได้ตามเดิม
