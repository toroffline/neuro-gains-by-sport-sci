# สิ่งที่แสดงในภาพ: คู่มือวัตถุ

หมายเลขตรงกับป้ายกำกับในวิดีโอและหน้าเว็บ ภาพเป็นโมเดลสรุปเพื่อการเรียนรู้ รูปทรง ขนาด จำนวนอนุภาค และเวลาที่บีบย่อ ไม่ใช่ข้อมูลกายวิภาคหรือผลตรวจรายบุคคล

## 1. ภาพรวมร่างกาย

### 1. สมอง

จุดสีคอรัลในศีรษะแทนสมอง ซึ่งเป็นส่วนของระบบประสาท

### 2. หัวใจ

จุดบริเวณทรวงอกแทนหัวใจ ตำแหน่งในหุ่นเป็นภาพสรุป

### 3. บริเวณต่อมหมวกไตและรังไข่

จุดในช่องท้องและอุ้งเชิงกรานระบุตำแหน่งอวัยวะต่อมไร้ท่อ ซึ่งจะขยายให้ดูในฉากถัดไป

### 4. นักวิ่งและผู้ยกดัมเบล

นักวิ่งแทนการฝึกแอโรบิก ผู้ยกดัมเบลแทนการฝึกแรงต้าน

## 2. เลือด–สมองและเซโรโทนิน

### 1. อัลบูมิน

โปรตีนสีน้ำเงินเป็นพู แทนอัลบูมินที่จับทริปโตเฟนในพลาสมา

### 2. กรดไขมันอิสระ (FFA)

สายลูกปัดสีส้มแทนกรดไขมันที่อาจแย่งตำแหน่งจับบนอัลบูมิน

### 3. หลอดเลือด / ภาพตัด

ผนังสีชมพูล้อมช่องภายในหลอดเลือด แผ่นสีคอรัลคือเม็ดเลือดแดง ไม่ใช่ฮอร์โมน

### 4. เส้นใยกล้ามเนื้อและ BCAA

เส้นขนานมีลายพาดแทนเส้นใยกล้ามเนื้อ จุดกรดอะมิโนสายโซ่กิ่ง (BCAA) สีน้ำเงินเคลื่อนเข้าหากล้ามเนื้อ

### 5. แนวกั้นเลือด–สมองและ LAT1

แถวเซลล์แทนแนวกั้นเลือด–สมอง โปรตีนสีน้ำเงินแทน LAT1 จุดสีทองคือทริปโตเฟนอิสระ

### 6. ราเฟนิวเคลียสในก้านสมอง

จุดคอรัลอยู่ในก้านสมองใต้สมองใหญ่ แทนกลุ่มเซลล์ประสาทที่เกี่ยวข้องกับเซโรโทนิน

## 3. การเปลี่ยนแปลง P4 เฉียบพลัน

### 1. ช่องพลาสมา

ภาพตัดหลอดเลือดแสดงช่องของเหลวที่เล็กลง โดยคงจำนวนอนุภาคตัวอย่างเท่าเดิม

### 2. อนุภาคแทน P4

จุดทองแทนโปรเจสเตอโรน การอยู่ใกล้กันขึ้นสื่อความเข้มข้น ไม่ใช่อัตราการหลั่งที่วัดจริง

### 3. การเคลื่อนย้ายของเหลว

หยดสีน้ำเงินนอกหลอดเลือดแสดงการเคลื่อนย้ายของเหลว

### 4. ต่อมหมวกไตเหนือไต

ส่วนคล้ายหมวกสีทองคือต่อมหมวกไต ส่วนรูปถั่วด้านล่างคือไต ใช้เป็นจุดอ้างอิงตำแหน่ง

### 5. รังไข่ / คอร์ปัสลูเทียม

ภาพตัดรังไข่มีฟอลลิเคิลและคอร์ปัสลูเทียมสีทอง การมีส่วนสร้างฮอร์โมนขึ้นกับระยะรอบเดือน

## 4. การปรับตัวระยะยาว

### 1. ไฮโปทาลามัส

จุดใต้สมองแทนบริเวณไฮโปทาลามัส ไม่ได้ใช้ทั้งสมองแทนอวัยวะนี้

### 2. ต่อมใต้สมอง

ต่อมขนาดเล็กสองพูต่อกับสมองด้วยก้าน ลูกศรสรุปสัญญาณไปยังรังไข่

### 3. รังไข่และมาตรวัดพลังงาน

รังไข่เป็นปลายทางในภาพแกน HPO มาตรวัดเป็นสัญลักษณ์พลังงานที่เหลือใช้ ไม่ใช่ผลตรวจ

### 4. กระดูกยาว / ภาพตัด

เปลือกกระดูกชั้นนอกและโครงข่ายกระดูกด้านใน ช่วยแยกส่วนโครงสร้างให้เห็น

### 5. เซลล์สร้างกระดูกและแรงกระทำ

เซลล์สีทองบนผิวแทนเซลล์สร้างกระดูก ดัมเบลและลูกศรแทนแรงกระทำที่ส่งผลเมื่อเวลาผ่านไป

## 5. การประยุกต์ใช้

### 1. กลูโคส / โครงร่างโมเลกุล

โมเดลวงแหวนและพันธะสรุปการเชื่อมต่อของกลูโคส สีน้ำเงินคือคาร์บอน คอรัลคือออกซิเจน ไม่แสดงไฮโดรเจนหรือสเตอริโอเคมี

### 2. หลอดเก็บตัวอย่างเลือด

กระบอกมีฝาบรรจุตัวอย่างเลือด แทนการเก็บตัวอย่าง ไม่ใช่การจำลองผลเครื่องตรวจ

### 3. การตรวจ P4 ตามรอบเดือน

สัญลักษณ์เวลาเตือนให้เลือกช่วงเก็บตัวอย่างตามรอบเดือนของแต่ละบุคคล
